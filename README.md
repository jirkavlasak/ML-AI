Toto repozitář obsahuje několik menších projektů strojového učení, které pokrývají různé techniky a oblasti – od klasické predikce na strukturovaných datech až po zpracování obrazu pomocí neuronových sítí.

📂 Projekty
1. Titanic Survivor Prediction

Úkol: Predikce přežití cestujících na lodi Titanic

Použité metody: klasifikace, feature engineering, logistická regrese, decision trees

Dataset: Kaggle Titanic dataset

2. Age Prediction Based on Country

Úkol: Predikce věku uživatele na základě země a dalších demografických údajů

Použité metody: regresní modely (Linear Regression, Random Forest Regressor)

Dataset: vlastní/veřejně dostupný (doplň)

3. CNN Image Processing & Labeling

Úkol: Rozpoznávání objektů / klasifikace obrázků pomocí konvolučních neuronových sítí (CNN)

Použité metody: Convolutional Neural Networks (Keras / PyTorch / TensorFlow)

Dataset: např. MNIST, CIFAR-10 nebo vlastní dataset (doplň)

4. DNA Prediction

Úkol: Predikce genetických vlastností na základě DNA sekvencí

Použité metody: sekvenční modely, one-hot encoding sekvencí, RNN/LSTM (dle implementace)

Dataset: biologické/genomické datasety (doplň)

5. Dimensionality Reduction & Binary Classification

Úkol: Redukce dimenzionality a následná binární klasifikace

Použité metody: PCA, t-SNE, klasifikátory (SVM, Logistic Regression, Random Forest)

Dataset: např. UCI Machine Learning Repository (doplň)
